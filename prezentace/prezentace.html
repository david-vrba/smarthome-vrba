05 — Opravy

Co jsme opravili

FIX 01

Tailwind CDN → Inline CSS

Synchronní <script> stahoval 127KB JS, spustil JIT kompilaci, vygeneroval CSS. Nahrazeno ~190 ručně extrahovanými utility třídami přímo v <style>.

−1,524ms LCP
FIX 02

Google Fonts → Async Loading

Render-blocking <link rel="stylesheet"> nahrazen trikem media="print" onload="this.media='all'". Text se zobrazí okamžitě, font se načte na pozadí.

−1,458ms LCP
FIX 03

Preload URL → Správný obrázek

Preload odkazoval na Unsplash, ale skutečný hero obrázek je z e-spirit.cloud. Opraveno + přidán preconnect k image hostu.

−300ms LCP
FIX 04

Paper.js → Pouze desktop

67KB knihovna pro tekutý blob efekt se načítala i na mobilu, kde je sotva viditelná. Nyní se načítá podmíněně: if (innerWidth > 1024).

−67KB na mobilu

14 — Nasazení & hosting

Kam web nasadit?

Výstupem je veřejný odkaz. Porovnali jsme free hostingy pro statický web — liší se hlavně přenosem dat a doménou, ne technicky.

Hosting Výchozí doména Přenos zdarma Serverless Háček
Cloudflare Pages .pages.dev ♾️ neomezeně ✅ UI techničtější
Vercel .vercel.app 100 GB/měs ✅ komerce jen placené
Netlify .netlify.app 100 GB/měs ✅ podobné Vercelu
GitHub Pages .github.io/<repo>/ ~100 GB (měkký) ❌ jen statika, podcesta
ARGUMENTACE

Rozhoduje přenos, ne technika

Pro statický web zvládnou vše. Cloudflare = neomezený přenos zdarma; Vercel = nejlepší DX; GitHub Pages = nulová závislost a web u kódu.

A 3D?

3D běží v prohlížeči klienta

WebGL/Three.js počítá GPU návštěvníka — host posílá jen statické soubory. I komplexní 3D jde i na GitHub Pages; limit je jen velikost assetů a přenos.

15 — Forma vs. sdělení

Nejdřív co děláme. Pak teprve efekt.

Největší 3D weby vypadají božsky — a po pěti minutách pořád nevíš, co ta firma vlastně dělá. To je past. My ji obešli.

PAST · zentry.com

Majestátní 3D, nulové sdělení

Vizuálně jeden z nejlepších webů, co existují. Jenže po 5 minutách scrollování pořád nevíš, co je to za firmu a co prodává. Forma pohřbila obsah — komické, kolik peněz a designu padlo na něco, co nikdo „nepřečte".

NÁŠ PŘÍSTUP · SmartHome.cz

Za vteřinu jasné, pak paráda

Hero + produkty + ceník = okamžitě víš, co děláme a za kolik. Teprve pak má 3D show prostor — schovaná pod /o-mne, kde je efekt účelem a žádné sdělení neničí.

STRÁNKA „O ZAKLADATELI" — HYBRIDNÍ 3D (plain HTML + CDN, bez buildu)
Jasný hero (kdo + co) → ① Real-time WebGL (Three.js) → ② Obrazová sekvence (let dronem) → Pointa: forma ≠ sdělení

Jeden Lenis + GSAP scroll žene obě techniky, vždy běží jen jedna → spektákl bez ztráty výkonu i bez build systému.
